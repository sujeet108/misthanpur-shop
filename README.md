# Misthanpur — Mithai & Snacks

Mobile-first ordering website for Misthanpur, Juranchhapra Road No. 2, Muzaffarpur, Bihar.

- Customer storefront with category filters and cart
- Checkout and WhatsApp pre-filled order message to +91 98012 65197
- Supabase products, orders, realtime updates and phone OTP admin login
- Admin console at `/admin` for product and order management
- Vercel deployment configuration
